# 苔原小镇 · 三夜求生

[直接在线试玩](https://bisoubisou0905.github.io/mossbound-godot-playtest/)

Godot 原生版本的网页试玩包。打开网页即可开始，无需登录或安装。首次加载需要下载引擎与美术资源，后续会利用浏览器缓存。

## 林间营地美术更新

- 完整林地场景与昼夜渐变，木桩和绳索标记可用营地。
- 顶部委托改为挂纸告示牌，商品摆在补给摊位，回收使用独立交易箱。
- 生命条、三格饱食、太阳/月亮和金币组成紧凑状态栏；长说明收为情境提示。
- 主要资源点和建筑使用手绘风格透明素材；人物动作与可堆叠物品加强轮廓和配色。
- 配方手记、营地菜单与旅途馈赠统一成木框和纸张样式。原有进度与规则兼容。

## 合筑守夜：这一版的核心

白天开包、采集与制造 → 同级守备棋子二合进阶 → 把阿苔布置进营火与掩体的重叠范围 → 守夜 → 三选一旅途馈赠 → 调整下一天的营地。

- 营火：2 原木 + 1 石料，由阿苔制造；范围内加攻，同级二合至三级，效果为 +1 / +3 / +5。
- 掩体：1 原木 + 2 石料，由阿苔制造；范围内减伤，同级二合至三级，效果为 1 / 2 / 3。
- 同类光环只取最强。合并节省空间、提高强度，但减少覆盖据点。白天布阵，入夜建筑固定，人物仍可移动。
- 守过前两夜，各出现一次随机三选一强化：采集、攻击、守备范围、治疗、价格或扩地。选择与候选项都会存档，重载不会重抽。
- 默认拖动整组，Ctrl 拖动拿单件，S 拆分；也支持先点棋子，再点目标或空地。配方自动消耗所需数量，多余材料返还。
- 建成两件设施后可主动准备第一夜，无需等完倒计时。

这仍是可暂停的实时生存原型，不是完整的回合制战棋。当前同时支持一个建筑材料组。

## 食物与实物金币

- 开拓包逐件翻出六种内容，新增有限的浆果丛和一份初始浆果；采食资源包可持续补充食物来源。
- 阿苔负责采果。将两份浆果拖到营火，再把阿苔拖过去，6 秒烹成一份热餐；离开即暂停。
- 饱食度为 0–3，初始 2。入夜先减 1，再从棋盘自动吃一份，优先热餐。浆果补 1 饱食；热餐补 3 并恢复 3 生命。也可拖食物给人物吃。
- 饱食 1 时采集稍慢；饱食 0 时采集更慢、攻击减 1，缺餐当晚再失去 2 生命。顶部显示饱食与今晚的用餐预告。
- 金币始终是棋盘上的实物。拖一堆金币到顶部商品，会只扣价格、留下余款；直接点商品会从场上可用金币中凑款。没有存进钱袋的额外步骤。
- 购买的包和物品落回棋盘；棋盘没有空位则不扣钱。旧存档的钱袋余额会一次性迁回棋盘。

## 怎么玩

- 开局逐次点击开拓包，翻出树、矿石、初始木石、浆果丛和口粮，再把阿苔拖到资源旁采集。
- 默认拖动整组；按住 Ctrl 拖动拿一件。
- 把材料拖到顶部告示板完成订单，金币会掉回棋盘，可直接用于购买。
- 主题包逐次翻出三件物资：保证一个有限资源点与原料，另有随机原料、木板或治疗药。
- 把 3 原木与 1 石料直接拖在一起，再把阿苔拖过去，自动制造木工作坊。无需选配方或确认；右上配方手记仅供查阅。
- 工坊加工也需要阿苔；拖走人物则暂停。点击材料组可以拆开并返还材料。当前同时支持一个建筑材料组。
- 木工作坊建成后出现木匠委托，石工作坊建成后出现修路委托，均可重复交付。任务只给金币，科技由玩家自行制造。
- 为阿苔制作装备，活过三夜。生命归零即结束。

按空格暂停。存档留在当前浏览器，重新打开时暂停；设备之间不自动同步。手机建议横屏，当前优先保证桌面操作体验。

## 发布

`web/` 是 Godot 4.7 Compatibility、单线程 Web 导出产物，使用 WebAssembly 与 WebGL 2。更新此目录并推送到 `main` 后，GitHub Actions 会实际运行 Chromium 检查采集、堆叠交付、订单奖励、实物金币付款、购买开包和食物喂食，通过后部署 GitHub Pages。

编辑用的 Godot 工程保留在本地；这个仓库存放可直接部署的网页构建、测试和部署配置。网页包不能通过双击 `index.html` 运行，应使用在线地址或 HTTP 服务器。

测试截图可在 Actions 的 `browser-checks` 附件查看。`?qa=1` 仅供独立自动检查，会禁用存档读写；正常试玩请使用不带参数的链接。
